# Qwen 视频检验：操作与验收

## 配置与测试

在本机 `http://127.0.0.1:8501` 的“运行状态 → Qwen API 设置”中管理密钥。密钥通过 Windows 凭据管理器保存，独立于 DeepSeek，重启后仍有效。输入新 Key 后保存可替换旧 Key；已保存的密钥不会回填到网页。

模型默认 `qwen3-vl-32b-thinking`，Base URL 默认 `https://dashscope.aliyuncs.com/compatible-mode/v1`。这组配置已使用本机保存的 Key 实测成功。可修改为有权限使用的 Qwen 视觉模型及官方服务地址，然后点击“保存模型与调用设置”。密钥与非敏感设置分别存储，后者在 `runs/settings/qwen.json`。

“测试 Qwen 连接”发送一个简短文字请求，验证当前 Key、模型和地址能否返回最终答案，不上传视频；同样消耗请求额度。该模型为思考版，代码保留思考能力，但只解析最终答案，不保存或展示思考过程。

8502是分享服务，即使从127.0.0.1访问也不显示管理入口。它与8501共用凭据、模型设置和请求额度。默认允许公网 Qwen 检验，分享者可在本机关闭。

## 使用示例视频

1. 打开本机或原公网地址。
2. 在“上传视频”中选择项目目录下 `assets/demo_videos/head_turn_control.mp4`，该视频约5秒。
3. 选择 DeepSeek 解析，填写“检测视频中的人员是否出现明显转头动作，指出对应画面。”
4. 点击“生成场景配置”。需求适合视觉检验时，页面显示“可以使用 Qwen 检验此需求。”和检验按钮。
5. 点击“使用 Qwen 检验”。此操作会将需求和采样画面发送给百炼，产生 API 用量。
6. 在“Qwen 检验结果”中查看标注视频、区间结果、疑似事件、依据和证据截图。可下载视频、JSON报告、CSV及证据截图包。视频预览保持比例，宽不超过640、高不超过480像素；截图预览不超过320×360像素，不放大原图。

更换视频会清除旧结果；更改需求会清除旧配置及结果，需要重新解析。示例视频保留在本机目录，网页不再提供专用示例栏目；也可以直接上传自己的视频。

## 自己的视频

上传不超过60秒的视频，选择 DeepSeek 解析，输入具体、可观察的行为，例如“检测人员是否接打电话”或“检测人员未戴安全帽”。已有小模型能完成的需求继续使用本地分析；本地不支持且适合画面检验的需求才提供 Qwen 入口。模糊要求、短信通知、身份识别、心理意图等不会直接进入视觉检验。严格连续时长不能由稀疏画面保证，应使用已有逐帧规则或修改需求。

建议先用清晰、短小的片段测试。“检测是否有人佩戴红色安全帽。”可作为内置转头视频的反例；注意这是“佩戴红色安全帽”，与“未戴安全帽”的判断方向相反。

## 结果含义与限制

- **疑似发现**：初筛与加密复核均发现，附原始帧编号和时间戳。仍不是人工确认。
- **采样未发现**：所给画面未发现符合条件的证据，不能保证整段视频没有事件。
- **无法判断**：画面或语义不足，或初筛与复核不一致，需要查看证据。
- **调用失败**：超时、配额、权限、格式错误等明确报错，不生成“未发现”结果，不缓存失败。

8秒窗口、1秒重叠，初筛约2 FPS，疑似窗口复核约4 FPS；低帧率视频使用实际可用帧。画面长边最多640像素，保持比例、不放大。由原始帧编号和帧率计算时间戳，编号必须来自本次发送的画面。模型不能自行编造位置框或证据时间。视频顶栏标示的是“抽帧检验区间”，不表示事件在整个区间持续发生。导出的标注视频不保留音轨。

单次最多18次 Qwen 请求；本机与公网合计默认每天40次，可在本机设置1–200次。失败请求也占次数，这个计数是程序限额，不等于供应商计费记录。跨进程同时只运行一个 Qwen 任务。请求单次网络等待上限90秒，不自动重试付费请求；模型未给完整最终答案时提示失败。相同视频内容、需求、模型、地址及采样版本复用成功缓存，不重复收费。缓存与证据在本机 `runs/qwen/`。

采样可能漏掉快速动作，低分辨率可能遗漏小物体。当前验收是功能验证，不是准确率评测；复杂任务上线前仍需准备标注样例统计误报和漏报。

## 本次真实验收

- 正例：内置转头视频，需求为“检测视频中的人员是否出现明显转头动作，指出对应画面。”DeepSeek 路由到 Qwen；初筛及复核共2次请求，约56.19秒，1个疑似事件，证据帧5、10、15（约0.251、0.502、0.753秒）。结果在 `runs/qwen/inspection-abdcd8327445/`。
- 反例：相同视频，需求为“检测是否有人佩戴红色安全帽。”1次请求，约28.31秒，采样未发现、0个事件。结果在 `runs/qwen/inspection-02a11c391349/`。
- 自动测试覆盖接口错误脱敏、输出截断、证据编号、复核分歧、缓存、时长上限、跨进程额度、设置存储、界面路由及原有功能。公网真实会话已验证加载示例、DeepSeek 路由、缓存结果播放及全部下载入口，记录在 `runs/share/qwen-public-verification.json`。

可通过 `.\.venv\Scripts\python.exe scripts/verify_qwen_demo.py` 重跑正例路由验收；会调用 DeepSeek，Qwen已有相同成功缓存时会直接复用。
