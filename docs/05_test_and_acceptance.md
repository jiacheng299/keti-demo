# Demo 测试与验收标准

## 1 验收原则

所有“已完成”结论必须由测试输出、运行记录、生成文件或现场演示支持。公开视频上的结果只证明该演示素材上的效果，不代表跨场景精度指标。

## 2 单元测试

### SceneSpec 与模型注册

- 有效的边防和火灾 SceneSpec 可通过校验。
- 未注册模型、未知场景、未知规则和非法参数被拒绝。
- 目标类别必须由所选模型支持。
- DeepSeek 输出中的代码或命令字段不得执行。

### 视频模块

- 可读取视频宽、高、帧率、帧数和时长。
- 不可解码文件返回明确错误。
- 抽帧器按配置节奏选择帧。
- 正常完成、中途停止和发生异常时均释放视频句柄。
- 输出视频可重新打开和读取。

### 跟踪与规则

- 同一目标连续出现时短期 Track ID 保持稳定。
- 区域外目标不产生进入事件。
- 目标进入禁区后产生一次进入事件。
- 轨迹穿过警戒线后产生跨线事件。
- 停留时间未达到阈值不产生滞留告警。
- 连续帧数不足时火灾事件保持疑似或不告警。
- 达到连续帧阈值后产生确认告警。
- 冷却期内相同目标和事件不重复记录。

### 事件导出

- 每条事件具有唯一 ID、场景、事件类型和视频时间。
- 确认事件有对应截图。
- JSON 与 CSV 的事件数量及核心字段一致。
- 每次运行输出到独立目录，不覆盖先前运行。

## 3 集成测试

### 边防视频

输入固定公开视频与边防 SceneSpec。验收模型加载、人员/车辆检测、跟踪、至少一种事件规则、标注视频、事件截图和 JSON/CSV 输出。

### 火灾视频

输入固定公开视频与火灾 SceneSpec。验收火焰或烟雾检测、连续帧确认、疑似/确认状态、事件截图和 JSON/CSV 输出。

### 降级路径

- 不设置 DeepSeek API Key 时，离线模板可选择和运行。
- DeepSeek 超时或返回无效 JSON 时，页面给出说明并允许改用模板。
- 缺失模型权重时，任务被阻止且错误信息说明模型 ID 和预期权重位置。

## 4 答辩验收流程

1. 展示场景模板和模型注册配置。
2. 上传边防视频并输入自然语言请求。
3. 展示 SceneSpec 和选择的边防模型。
4. 播放标注结果并查看越界、禁区或滞留事件。
5. 上传火灾视频并选择自然语言配置或模板。
6. 展示火灾模型切换和连续帧告警。
7. 查看统一事件列表、截图、JSON、CSV 和结果视频。
8. 断开 API 后使用模板完成主要分析流程。

## 5 通过标准

- 两类模型在目标笔记本 CPU 环境可启动。
- 两个固定视频都能完整处理。
- 边防至少一种事件和火灾连续帧事件可重复触发。
- 场景切换通过配置完成，无需改分析主流程代码。
- 事件记录包含视频时间和截图。
- JSON、CSV 和页面事件数量一致。
- API 不可用时模板模式可完成演示。
- 整体演示不超过 5 分钟。

## 6 性能与效果记录

每种模型至少记录：权重来源与版本、输入尺寸、检测帧间隔、置信度阈值、视频时长、处理时长、平均处理速度、正样本表现、负样本误报、已知限制。

项目书提出的正式准确率、开放新类准确率、事件检出率、误报率、两路并发和 5 秒响应指标，只有在预先定义测试集、标注方法和测量流程后才能报告。单段演示视频结果不得替代正式指标。

## 7 Git 内容审核

提交前检查：

- `.env`、API Key、令牌和个人凭据不在暂存区。
- 模型权重、个人视频、生成结果和文档审查中间件被忽略。
- 公开模型和视频来源及许可证已记录。
- `git diff --cached --check` 无空白错误。
- 运行相关测试并把准确输出写入每日日志。
