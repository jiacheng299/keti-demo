# Demo 答辩演示指南

## 1 演示前准备

- 使用本机 Python 虚拟环境。
- 确认依赖和应用可启动。
- 确认边防、火灾权重已在本地，网络中断时不需要重新下载。
- 确认两段固定公开视频可读取。
- 确认 DeepSeek API Key 已通过本机环境变量设置；不得写入文档或代码。
- 分别运行边防和火灾流程，确认输出目录中包含结果视频、事件记录和截图。
- 另备已生成的结果视频，现场推理过慢时可直接播放。
- 清理页面中的私人路径、账号信息和不适合展示的日志。

## 2 五分钟演示流程

### 0:00–0:30 项目目标

说明项目目标是验证开放场景视觉语义认知链路。本 Demo 展示一个统一平台调用不同场景小模型，而非宣称单个模型能识别所有目标。

### 0:30–1:00 平台结构

展示自然语言解析、SceneSpec、模型路由、场景规则和统一事件输出。说明 DeepSeek 负责配置解析，本地小模型负责视频推理。

### 1:00–2:30 边防场景

上传固定边防视频。输入“有人越过警戒线后立即报警”，展示解析后的目标、模型和跨线规则。启动分析，查看检测框、跟踪 ID、警戒线和事件时间。

### 2:30–4:00 火灾场景

切换至固定火灾视频。输入“连续检测到火焰超过设定帧数后报警”，展示火灾模型和连续帧阈值。查看疑似到确认状态及事件截图。

### 4:00–4:40 通用性与结果

展示两个场景使用不同模型和规则，但共享视频处理、事件格式、页面和导出能力。下载或查看 JSON、CSV 和标注结果视频。

### 4:40–5:00 边界说明

说明本期仅支持视频文件和单路 CPU 分析；摄像头、RTSP、本地视觉大模型、多路并发和正式精度评估属于后续工作。

## 3 常见问题建议回答

### 为什么不使用一个模型处理所有场景？

不同业务场景的视觉目标差异明显。Demo 采用共享平台加专用小模型插件，按场景选择模型，同时复用视频、规则、事件和展示能力。

### 大模型在系统中做什么？

DeepSeek 将自然语言需求解析成经过白名单和 Schema 校验的配置。视频画面交给本地视觉模型处理，大模型不会返回或执行代码。

### 为什么没有本地部署视觉大模型？

当前设备只有 CPU，无法稳定运行本地多模态大模型。Demo 使用 DeepSeek API 做文本配置解析，并由本地轻量模型完成视觉推理。

### 是否证明达到项目书精度指标？

答辩 Demo 证明选定模型在指定公开视频和规则下可以完成端到端流程。正式准确率、开放目标准确率、误报率和并发指标需要独立标注测试集与系统化测量，不能由少量演示视频推断。

### 网络断开怎么办？

使用预设场景模板继续分析。模型权重和演示视频提前保存在本机；只有自然语言自动解析需要调用 DeepSeek。

### 后续如何扩展摄像头或 RTSP？

将统一视频源接口扩展为文件、摄像头和 RTSP 实现，检测适配器、规则和事件输出保持不变。该接口扩展需在后续开发和硬件测试中验证。

## 4 故障处理顺序

1. API 不可用：切换离线模板。
2. 推理太慢：减小输入尺寸、增加抽帧间隔或播放预生成结果。
3. 视频打不开：使用固定备用视频。
4. 火灾告警不触发：切换已验证的正样本视频；确认阈值和连续帧数设置。
5. 权重加载失败：使用备用权重或播放对应预生成结果，并明确标注为预先处理结果。
6. 页面异常：重新启动应用，使用保存的样例配置和本地输出文件继续讲解。

## 5 演示诚信要求

- 现场推理和预生成结果要明确区分。
- 仅报告实际测得的处理速度和样例表现。
- 不把模板选择描述成 DeepSeek 生成。
- 不把公开样例的表现描述为普遍识别率。
- 对尚未实现的摄像头、并发和生产部署能力明确标为后续计划。
