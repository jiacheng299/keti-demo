# 开放场景视觉语义认知 Demo 功能说明

## 1 用途与范围

本 Demo 用于答辩展示开放场景视觉语义认知平台的核心流程：上传视频、描述需求、生成结构化场景配置、选择对应小模型、按规则判断事件并导出结果。当前规划包含边防和火灾两个场景插件，运行条件为仅 CPU 的个人笔记本电脑。

本说明区分设计目标与实际实现状态。功能只有在代码完成并通过本地测试后，才能标记为“已实现”。

## 2 使用流程

1. 启动本地 Streamlit 页面。
2. 上传 MP4、AVI 或 MOV 格式的视频。
3. 输入自然语言场景要求，或选用离线预设模板。
4. 查看系统生成的 SceneSpec，并确认场景、模型和规则。
5. 启动分析，查看进度和检测结果。
6. 查看检测框、禁区和事件记录。
7. 下载结果视频、事件 JSON、CSV 和运行摘要。

## 3 页面功能

### 3.1 运行状态

页面已显示 DeepSeek API 是否可用、模型加载策略、当前场景配置、当前模型和视频元数据。模型只在分析期间加载，完成或失败后自动释放。

### 3.2 视频上传

用户可上传 MP4、AVI、MOV、OGV 或 MKV 视频。系统检查扩展名、视频可解码性和元数据，显示分辨率、帧率、帧数及时长。上传内容按哈希值安全落盘，不使用原文件名拼接路径。CPU 性能不足时可按设置抽帧处理，结果视频在任务完成后转为浏览器兼容的 H.264 格式并播放。

### 3.3 自然语言场景设置

用户可输入例如“有人进入禁止区域后立即报警”或“连续检测到火焰超过 8 帧后报警”。DeepSeek 只解析语义并生成 SceneSpec，不直接分析视频，也不得生成可执行代码。

当前页面可在“离线模板”和“DeepSeek 解析”之间切换。后端已实现 JSON Output 请求、超时/网络失败重试一次、无效模型输出重试一次，以及 SceneSpec、模型、目标类别、规则和参数白名单校验。API 不可用、Key 缺失或两次输出无效时，自动降级到用户选定的预设模板。生成后的 SceneSpec 会在页面展示，用户确认后再启动分析。已使用真实 DeepSeek API 将“连续检测到火焰 8 帧后报警，允许 1 帧短暂漏检，告警冷却 10 秒”解析为合法火灾 SceneSpec。

### 3.4 离线模板

已提供以下模板：

- 边防人员禁区：人员进入配置的多边形区域。
- 边防车辆禁区：车辆进入配置的多边形区域。
- 边防滞留：人员进入区域并停留超过阈值。
- 火灾检测：火焰或烟雾连续出现若干帧。

模板值可在用户界面查看和确认。模板用于保证断网时演示仍能继续；参数编辑暂不在本期页面范围内。

## 4 场景插件

### 4.1 边防插件

使用通用轻量目标检测模型识别人和常见车辆。可结合目标跟踪与空间规则，判断进入禁区、离开禁区或区域滞留。演示不涉及人员身份识别或军事目标识别。

### 4.2 火灾插件

使用公开火焰/烟雾检测权重识别画面目标，并使用连续帧确认减少单帧误检。模型效果须以固定视频测试为准。若烟雾类别在公开权重或 CPU 推理下不稳定，本 Demo 范围可收敛为火焰检测。

## 5 通用规则

计划支持以下规则组合：

- 目标出现。
- 进入或离开多边形区域。
- 停留时间超过阈值。
- 目标数量超过阈值。
- 连续多帧检测满足条件。
- 置信度超过阈值。
- 多条件 AND / OR 组合。

规则使用统一输入，不直接依赖特定模型的返回类型。可组合规则范围以实际完成并通过测试的规则为准。

## 6 结果展示

当前完整分析流水线已在结果视频中显示检测框、类别和跟踪 ID。置信度保留在结构化检测和事件数据中，不叠加到视频画面。页面已展示处理帧数、推理帧数、检测数量、事件数量、模型和分析耗时，并以中文事件表展示事件编号、类型、目标类别、目标 ID、视频时间和状态。禁区多边形和目标轨迹暂未叠加到视频。导出事件仍保留场景、置信度、触发规则、模型名称和截图路径等完整字段。

计划展示的统计包括处理帧数、处理速度、检测目标数、告警次数、事件类型数量和推理耗时。仅显示能够可靠测量的指标。

## 7 文件导出

每次运行使用独立目录，建议结构如下：

```text
runs/<run_id>/
├── config.json
├── events.json
├── events.csv
├── summary.json
├── snapshots/
│   └── evt-000001.jpg
└── result.mp4
```

当前后端已实现 `config.json`、`events.json`、`events.csv`、`summary.json` 和确认事件 JPEG 截图。`events.json` 保留完整结构化字段；`events.csv` 使用 UTF-8 BOM，时间统一保留三位小数；`summary.json` 记录总事件数、疑似/确认数、事件类型统计和运行指标。疑似事件不保存截图。

每次导出指定独立运行目录。全部内容先在内存中序列化，再通过同目录临时文件逐个原子替换；序列化或临时写入失败时保留旧文件。分析流水线生成 `result.mp4` 后，页面使用本地 FFmpeg 将其原子替换为 H.264/yuv420p 浏览器兼容文件。页面已提供结果视频、事件 JSON、事件 CSV、运行摘要和场景配置五个下载入口。保存结果时不包含 API Key。

## 8 安全与失败处理

- SceneSpec 的场景、模型、目标和规则必须来自白名单。
- 阈值必须经过范围校验。
- DeepSeek 返回值不得直接执行。
- API Key 通过环境变量读取，不写入仓库和普通日志。
- DeepSeek 不可用时使用离线模板。
- 缺少模型权重时阻止任务启动并说明所需文件。
- 视频损坏时在推理前提示用户。
- CPU 过慢时降低输入尺寸或增加抽帧间隔。
- 结果视频写入失败时尽量保留已生成的 JSON、CSV 和截图。

## 9 本期明确不含

- 摄像头或 RTSP 实时接入。
- 两路以上并发视频。
- 本地多模态大模型。
- 任意新目标的稳定零样本识别。
- 人员身份识别和跨摄像头身份关联。
- 模型训练、自动标注、数据库、登录权限和生产部署。
- 火势等级、蔓延预测和消防联动。
